BASIC CHECKS FOR MODERN WEB PAGE

☑ Practical Front-End Checklist

7 essential categories every designer should get right

1

HTML — Structure & Semantics

Foundation of your web page

ESSENTIAL ▼
HTML5 doctype
<html lang=""> set correctly
<head> before <body>
<header>, <main>, <footer> used correctly
Check if these semantic elements are properly used
One <h1> per page
Proper heading hierarchy (h1 → h2 → h3)
Basic check for presence of headings
Semantic elements (nav, section, article) where appropriate
Basic HTML structure
Checks for </html>, </head>, </body> tags
If this is wrong, everything else suffers.
2

Metadata — Core

Essential document information

ESSENTIAL ▼
<meta charset="UTF-8">
<meta name="viewport">
<title> that describes the page
<meta description> present
3

Navigation & Layout

Structure and user flow

ESSENTIAL ▼
Clear navigation structure
Checks for navigation links
<nav> inside <header>
<header> at the top
<main> contains the primary content
<footer> at the bottom
4

CSS — Styling

Visual consistency and design system

▼
Note: Most CSS checks require manual validation. Use the CSS Validator link for detailed analysis.
5

JavaScript — Behavior

Essential but limited functionality

ESSENTIAL ▼
External JS files used (not inline, unless tiny)
No inline onclick
No document.write()
No jQuery
Checks for jQuery in script sources
Scripts loaded with defer
6

Accessibility

Non-negotiable inclusive design

NON-NEGOTIABLE ▼
Semantic HTML instead of div soup
Checks ratio of semantic elements vs divs
Forms and buttons labeled
Basic check for form labels
Keyboard navigation works
Checks for focusable elements
lang attribute set on <html>
Already checked in HTML structure section
Note: For comprehensive accessibility testing, use the Accessibility Checker link. This tool provides basic checks only.
7

Performance — Basic

Not extreme, just sensible

▼
No blocking JS in <head>
Checks for non-defer, non-async scripts in head
Note: For comprehensive performance testing, use the Performance Test link. This tool provides basic checks only.
